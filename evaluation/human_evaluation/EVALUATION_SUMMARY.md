## Evaluation Criteria

Each poem is evaluated on 4 Arabic criteria (1-5 Likert scale):

1. **الالتزام بالقيود** (Compliance)
   - Does the poem follow the given instructions?

2. **الطلاقة اللغوية والإيقاع** (Fluency & Rhythm)
   - Is the language correct and does it flow naturally?

3. **التماسك والمعنى** (Coherence & Meaning)
   - Are the ideas logically connected and meaningful?

4. **الشاعرية والجمال الفني** (Poetic Quality & Artistry)
   - Is the poem beautiful and artistically excellent?

## Evaluation Workflow

### Step 1: Distribution
1. Send `generation_evaluation_sheet.xlsx` to annotators
2. Send `تعليمات_التقييم.txt` with instructions
3. **Keep `generation_model_mapping.json` confidential**

### Step 2: Annotation
- Annotators fill in scores (1-5) for each of 4 criteria
- Takes approximately 5-10 minutes per poem
- Total time: ~33-67 hours per annotator for 400 entries
- Optional: Add notes for any exceptional or problematic entries

### Step 3: Results Collection
- Collect filled Excel sheets from all annotators
- Verify all scores are present
- Address any missing evaluations

### Step 4: Results Analysis (Post-Evaluation)

## Technical Details

### Blind Design Implementation
- Model names are hidden: `model_1`, `model_2`, `model_3`, `model_4`
- Actual model names stored separately in JSON
- Rows shuffled: samples appear in random order
- Same seed (42) ensures reproducibility across runs

### Data Format

**Excel Sheet Columns:**
```
Column A: sample_id        → Unique identifier (sample_001 to sample_100)
Column B: model_id         → Blind model ID (model_1 to model_4)
Column C: instruction      → Poetry prompt/instruction given to model
Column D: model_generation → The poem generated by the model
Column E: [Score 1]        → الالتزام بالقيود (empty for annotator)
Column F: [Score 2]        → الطلاقة اللغوية والإيقاع (empty for annotator)
Column G: [Score 3]        → التماسك والمعنى (empty for annotator)
Column H: [Score 4]        → الشاعرية والجمال الفني (empty for annotator)
Column I: notes            → Optional notes from annotator
```

- Random seed: `42`

- Model ID shuffling deterministic and reproducible
